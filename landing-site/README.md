# one shop ai — 라미 글로벌 랜딩페이지

- 공개 랜딩: https://ramiai.dev/
- 프로덕션북: https://book.ramiai.dev/ — 기존 접근 설정 유지
- C 글로벌형을 최종 적용했다. A/B/C 선택 메뉴를 제거했으며 예전 concept 주소도 글로벌형으로 표시한다.
- 처음 방문 시 한국어를 기본으로 한다. 언어 선택은 URL과 브라우저에 저장하고 프로덕션북·데모 링크에도 전달한다.
- 지원 언어: 한국어, 영어, 베트남어, 중국어, 일본어, 크메르어, 인도네시아어, 라오어, 힌디어.
- 페이지 번역과 별개로 손님 대화 언어를 고를 수 있다. 샘플 샵 주모에는 한국어 기록이 표시된다는 점을 각 언어로 안내한다.
- 실제 AI와 결제는 연결하지 않았다. 모든 체험은 준비된 시나리오이다.
- 크메르어·라오어·힌디어는 로컬 Noto 글꼴을 사용한다. 라이선스는 dist/assets/fonts에 보관한다.

로컬 실행: `python3 -m http.server 4319 --bind 127.0.0.1 --directory dist`

문구 누락 및 지원 언어 검증: `node --test tests/*.test.mjs`

검토 이미지는 작업폴더의 검토 디렉터리에 저장한다. 이 디렉터리는 소스 배포에서 제외한다.
