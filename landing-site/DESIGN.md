# C 글로벌형 확정

- 원도메인 https://ramiai.dev/ 에서 로그인 없이 공개한다. 프로덕션북은 https://book.ramiai.dev/ 에 별도로 유지한다.
- A/B/C 검토 메뉴를 제거하고 글로벌형 한 가지로 확정한다. 예전 concept 쿼리는 제거하며 어떤 값이 있어도 글로벌형만 표시한다.
- 구성: 언어 선택 헤더 → 짧은 환대 메시지와 수채화 식탁 → 세 가지 도움 → 실제로 눌러보는 손님·샵 대화 → 라미와 시작하는 CTA.
- 흰색 #fff, 잉크 #172d46, 라미 블루 #aec8eb, 액션 블루 #315f99, 옅은 하늘 #f2f7fd. 브랜드와 그림이 중심이며 가짜 고객 수·후기·성과를 넣지 않는다.
- Pretendard를 기본으로 하고 크메르어·라오어·힌디어는 로컬 Noto 글꼴을 제공한다. 폰트 라이선스를 assets/fonts 안에 보관한다.
- 한국어를 처음 방문의 기본으로 한다. URL의 lang, 유효한 이전 선택, 한국어 순으로 결정한다. 모든 메뉴·버튼·본문·메타·이미지 설명과 시나리오 UI를 9개 언어로 제공한다.
- 손님 대화 언어는 페이지 언어와 독립적으로 선택할 수 있다. 샘플 샵 주모의 운영 언어가 한국어라는 문구를 각 언어로 설명하고 샵의 한국어 기록을 의도적으로 함께 보여준다.
- 언어를 바꾸면 데모와 프로덕션북 링크에도 같은 lang을 붙인다. 한국어는 root, 나머지는 ?lang=... 주소를 사용한다.
- 이미지의 비율을 유지한다. 라미 아바타는 배경과 곱하기 혼합하지 않고 흰 원 안에 표시한다. 언어별 줄바꿈과 line-height, 키보드 포커스, reduced-motion을 확인한다.
- 실제 AI·결제는 연결하지 않는다. 모든 대화는 로컬에 준비된 문장이다.
