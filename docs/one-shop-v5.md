# 원샵 5.0 변경 및 검증

2026-10-27. one ai의 원샵으로 앱과 9개 언어 프로덕션북을 변경했다. 기존 배포 주소, 브라우저 저장 키, API 이름은 저장된 샵과 공유 QR의 호환을 위해 유지한다. 캐릭터는 별도 로컬 시안으로 보관하며 사용자 확정 전에는 적용하지 않는다.

## 주문 접수

손님은 주문 전 매장 식사 또는 온라인 배달을 선택한다. 매장 식사는 테이블 번호를 묻고, QR의 번호가 있어도 최종 확인을 거친다. 번호가 없는 방문을 임의의 테이블에 배정하지 않는다. 온라인 주문은 배송 주소와 연락처, 선택 사항인 받는 분 이름을 입력하고 최종 주문 카드에서 확인한다.

`modu_orders.fulfillment`에는 확정 당시의 정보가 저장된다. Edge Function과 데이터베이스에서 필수 정보를 검증하고, 기존 가격 확인·중복 방지 트랜잭션과 함께 기록한다. 동일 요청을 다시 보내도 주문 및 주소가 중복 생성되거나 덮어써지지 않는다. 과거 주문의 출처는 추정하지 않고 정보 확인 필요로 표시한다.

사장님은 샵 현황에서 매장 식사·온라인 배달·접수 대기로 필터링할 수 있다. 주문별 테이블 번호 또는 배송 주소·연락처를 확인하며 매니저에게 주문 경로를 물을 수도 있다. 원래의 실시간 갱신을 사용한다. 실시간 알림 자체에는 주소와 전화번호를 포함하지 않고, 권한이 확인된 API가 데이터를 반환한다.

## 샘플과 연결 모드

주모 샘플에는 매장 주문 2건과 온라인 주문 2건이 있다. 이전 샘플 데이터는 초기화하지 않고 기존 시드 주문에만 출처 예시를 추가한다. 샘플의 손님 화면은 같은 브라우저의 샘플 저장 공간을 사용해 사장님 탭에 즉시 반영된다. 다른 기기의 샘플 로그인은 각각 독립된 예시다.

직접 등록된 샵의 공개 링크는 Supabase에 저장된 메뉴, 주문, 예약을 사용한다. 손님이 다른 기기로 QR에 접속해 주문할 수 있다. 사장님의 실제 이메일·Google 인증과 기기 간 계정 연결은 아직 연결하지 않았다. 실제 AI, 결제, 배달 업체 및 POS 전송도 실행하지 않는다.

## 검증

- `npm test`: 22개 통과. 9개 언어, 주문 필수 정보, 가격 변경, 중복 주문, 샘플 업그레이드, 기존 게임·예약 등.
- `npm run test:cloud`: 서버 가격·권한·중복 방지·예약·실시간 갱신 통합 검증 통과.
- `node scripts/verify-order-fulfillment.mjs`: 배송 정보와 테이블 저장, 재시도 정보 고정, 잘못된 입력 거부, 소유자 조회 및 다른 손님·공개 조회 격리 통과. 전용 개발 검증 샵에만 예시 주문을 만든다.
- 브라우저: 모바일 390 × 844에서 배송 정보 입력과 최종 주문, 테이블 12번 확인, 사장님 탭 갱신 및 주문 출처 필터 확인.
- Supabase 보안 점검: 이번 마이그레이션 적용 후 경고 없음.

입력 검증 코드는 `dist/shared/order-details.js`와 Edge Function에 동일하게 유지하며 테스트에서 일치 여부를 검사한다. 샘플 주소와 연락처는 가상 예시이며, 서버 검증용 관리 키는 git에서 제외한 `artifacts/`에만 보관한다.
