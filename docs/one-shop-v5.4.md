# 원샵 5.4 — 동그라미에서 온 라미

사용자가 승인한 파란 캐릭터의 이름을 **라미 / Rami**로 확정했다. 이름은 **동그라미**에서 따왔다. 플랫폼 이름은 원샵 / one shop ai를 유지한다.

## 결과물

- 프로덕션북에 라미 이야기, 24가지 표정, 6개 직업, 굿즈·상품권, BI·아이콘의 5개 섹션 추가. 기존 18개 사업 소개 섹션과 함께 제공.
- 24개 표정은 각각 다른 원본 이미지. 선택하면 큰 미리보기와 PNG 다운로드 링크가 함께 바뀐다. 모바일에서 미리보기는 섹션 안에 고정된다.
- 직업군: 매니저, 셰프, 바리스타, 서비스 담당, 마케터, 경리 담당. 역할별 PNG 다운로드 제공.
- 에코백, 머그, 키링, 스티커, 티셔츠 콘셉트와 상품권 목업. 상품권 시안은 미발행·결제 불가로 표시.
- 가로·세로 라미 로고 SVG, 상품권 SVG, 64/192/512px 아이콘 PNG와 70개 파일의 ZIP. 로고는 원본 캐릭터 픽셀을 포함하고 텍스트를 편집 가능하게 구성.
- 밝은 흰색 중심 배경, 굵은 카테고리 제목, 현재 장이 보이는 사이드바 자동 스크롤.
- 한국어·영어·베트남어·중국어·일본어·크메르어·인도네시아어·라오어·힌디어.
- 사장님앱에 샵 매니저 라미·라미 알림, 손님앱에 라미 이름과 소개. 대화 상태에 맞는 인사·생각·주문 이미지 연결.

## 파일

- 공개 에셋: `dist/assets/one-shop/rami/`
- 책 UI: `dist/rami-book.js`, `dist/rami-book.css`
- 다국어: `dist/shared/rami-copy.js`
- 로컬 제작 원본·프롬프트·검수: `design/one-shop-brand/rami-v5.4/`

새로운 WebP 이미지 33개 합계 약 640KB, 다운로드 PNG 30개 약 4.81MB, 전체 ZIP 약 6.15MB. Higgsfield GPT Image 2.5로 8회 생성했고 원본 시트를 기계적으로 분리·최적화했다. 공개 저장소에는 최적화한 결과물을 저장한다.

## 확인

- 기존 주문·예약·실시간 알림·상태 저장 관련 29개 테스트 통과.
- 9개 언어 각각 24표정/6역할/6설명/5섹션의 텍스트와 에셋 경로 확인.
- WebP 33개 고유 해시 확인, ZIP 70개 항목 무결성 확인.
- 데스크톱·390px 모바일에서 실제 브라우저로 표정 선택, 미리보기 고정, 목차 이동, 언어 전환과 BI·굿즈 확인. 9개 언어 모두 가로 넘침 없음.
- 손님앱에서 새 라미 이미지 로딩과 에이전트 이름, 사장님앱에서 라미 인사와 매니저 이름 확인. 콘솔 오류 없음.
- 실제 AI 및 결제 서비스 연결, 데이터베이스 구조 변경 없음.

인쇄용 생산 도면이나 플랫폼 심사를 통과한 메신저 이모티콘 상품이 아닌 브랜드 시안·웹 에셋이다. 번역은 기존 책과 동일하게 출시 전 현지 검수가 필요하다.
