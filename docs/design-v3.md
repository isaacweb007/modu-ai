# 대화 중심 UI · 3.0

사용자 지시: 그록처럼 간결한 대화 UI. 디자인 템플릿 선택을 제거하고 사장님은 매니저의 안내에 따라 가게를 개설한다. 손님 역시 대화에서 문의·주문·예약·데모 결제·포인트·보너스를 처리한다.

색상: graphite #171717, sidebar #101010, raised #242424, line #383838, text #f2f2f2, secondary #a4a4a4. Pretendard를 로컬 제공하며 한글·라틴 대화 본문은 16px/1.75, 작은 조작 문구는 12~14px. 동아시아/남아시아 문자에는 충분한 줄 간격을 둔다.

화면: 좌측 얇은 탐색 영역 + 중앙 최대 780px 대화 + 하단 고정 입력창. 작은 화면에서는 좌측 영역을 접고 대화와 입력창이 중심이다. 별도 음식 홈·상점 템플릿을 만들지 않는다. 매니저의 큰 첫 인사와 빈 입력창이 시작 화면이다. 메뉴·예약·결제·파일·QR은 대화 안의 확인 카드로 나타난다. 오너 대시보드는 하나이며 실제 저장된 데모 기록만 보여준다.

프런트엔드 디자인과 UI/UX Pro Max의 최소 조작·명확한 확인·44px 터치 영역 원칙을 적용한다. 추천 색상은 사용하지 않고 사용자가 지정한 그록 계열의 무채색 대화 화면을 따른다. 그록 상표·로고를 복제하지 않고 modu ai와 주모 정체성을 유지한다.

기존 2.0 이미지·게임 에셋은 보관한다. 운영 UI에서 5개 템플릿 선택은 제거한다. 가입·파일 분석·결제는 데모 범위를 명시한다. 업로드는 브라우저 IndexedDB에 보관하고 실제 GPT/OCR/POS/결제를 호출하지 않는다.
