# 검증 기록

2026-10-26, Codex 내장 브라우저에서 확인.

- 로컬 HTTP 200, JS 파일 두 개 구문 검사 통과.
- 표지 일러스트, 글꼴, 아이콘, 목차와 18개 장 렌더링.
- 영어 메뉴 전환 후 토스트 + 라테 합계 18,000원. 토스트 수량 2 / 라테 제거 후 합계 25,000원. 체험 주문 확인 후 장바구니 초기화 및 확인 메시지.
- 한국어·베트남어 추천 응답과 추천 메뉴 담기, 준비된 예시 응답 고지.
- 사장님 예시 정보 → 예시 메뉴 → 확인 체크 없이 진행 차단 → 확인 후 체험 링크 생성.
- QR 테이블 번호 12 입력 및 별도 인쇄 페이지에서 Table 12, 가게명, 실제 QR SVG와 연결 주소 확인.
- 사업 계산기: 100개 매장 × 29,000원 = 월 2,900,000원, 매장당 변동비 15,000원일 때 공헌이익 1,400,000원.
- 홍보·SNS 역할 탭의 콘텐츠 변경 확인.
- 논의 메모 입력 후 새로고침 시 보존 확인. 테스트 메모는 빈 값으로 초기화.
- 목차 검색과 모바일 목차 열기 확인.
- 390px / 768px iframe 뷰포트에서 반응형 확인. 스크롤바 제외 실제 폭 375 / 753px와 문서 폭 일치, 가로 넘침 없음.
- 점검 중 브라우저 console error/warn 없음.

한계: 실제 휴대폰 카메라 스캔과 실물 프린터 출력은 수행하지 않았다. A6 인쇄 스타일과 인쇄 페이지를 구현·시각 검토했다. 실제 GPT API, 메뉴 OCR, 계정·데이터베이스·결제·SNS·외부 주문은 체험 범위 밖이며 연결하지 않았다.
