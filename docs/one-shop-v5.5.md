# 원샵 5.5 — 한국어 기본값과 9개 언어 현지화

2026-10-27

프로덕션북, 사장님 데모, 손님 데모의 기본 진입 언어를 한국어로 통일했다. URL의 유효한 `lang`은 존중하고, 이전 브라우저 저장값이나 지원하지 않는 언어 때문에 기본 언어가 바뀌지 않는다. 화면에서 언어를 바꾸면 앱·프로덕션북·QR 링크에도 선택이 이어진다.

## 문구

- 한국어·영어·베트남어·중국어·일본어·크메르어·인도네시아어·라오어·힌디어 지원.
- 기존 10개 카탈로그를 검토해 비한국어 교정 824건을 반영했다. 한식 메뉴 설명, 주문·예약·상태 문구, 로그인, 라미 소개, 18개 본문 챕터, 5개 캐릭터 챕터를 포함한다.
- 한국어 원문도 중복 안내와 직역투를 정리했다. 개인정보 안내는 프로필 동의와 배달 연락처 입력, 로컬 샘플과 연결된 샵의 기록 저장을 구분한다.
- 라미 색상 이름과 타이포그래피 예문, 자료 링크도 선택 언어로 표시한다. 9개 언어 상품권 SVG를 추가하고 브랜드 키트에 포함했다. 고유 로고인 `원샵`, `라미`, `one shop ai`, `rami`는 브랜드 형태를 유지한다.
- 원어민 인적 감수 완료를 주장하지 않는다. 실제 출시 전 현지 검수가 필요하다.

## 표시와 보존

- 통화는 VND 그대로이며 환산하지 않는다. `Intl`을 사용해 언어별 숫자·통화·날짜 형식을 적용했다. 예약 시간은 시차 때문에 바뀌지 않는 매장 방문 시각으로 표시한다.
- 테이블 번호와 예약 인원에 각 언어의 어순을 적용했다.
- 예전 샘플의 메뉴, 재고, 업무, 주소, 자료 이름이 처음 선택한 언어에 고정되던 문제를 해결했다. 알려진 데모 원문과 일치하는 필드만 화면에서 바꾼다. 원본 상태를 수정하지 않으며 사용자가 편집한 내용, 실제 주문 금액, 배송 주소·연락처와 손님의 대화는 유지한다.
- 새로 누르는 주문 방식·정보 확인 버튼은 번역 키로 대화에 기록한다. 실제로 입력한 자유 대화는 원문으로 남는다. 카드 전용 메시지에 `null`이 보이던 문제도 수정했다.
- 예전 루트 QR 인쇄 경로를 현재의 다국어 QR 화면으로 연결했다.
- 크메르어·라오어·힌디어의 결합 문자에 맞게 앱의 줄 간격을 조정했다.

## 검증

- `npm test`: 34개 통과. 기존 주문·예약·실시간 기록·권한·게임·한도 검사와 기본 언어, 금액·예약 날짜, 샘플 현지화 시 사용자 편집 보존, 번역 카탈로그·상품권 검사를 포함한다.
- 390px 모바일 폭에서 프로덕션북·사장님 대시보드·손님 메뉴·예약 폼을 각각 9개 언어로 확인했다. 가로 넘침 및 메뉴 제목/버튼 잘림 없음. 주요 화면 브라우저 콘솔 오류 없음.
- 9개 상품권 SVG의 문자 배치, 힌디어 QR, 언어를 바꾼 뒤 언어 없는 URL로 다시 진입했을 때 한국어 표시를 확인했다.
- 로컬 검증 결과: `artifacts/localization-browser-v5.5.json`. 교정 근거: `artifacts/locale-review-*.json` (Git 제외).

실제 AI·OCR·결제·POS를 추가하지 않았다. 구독 결제나 실제 서비스 상품권을 발행하지 않는다.

공개 주모 데모 샵의 기존 저장 메뉴도 같은 표시 어댑터를 사용한다. 설정된 공개 샘플 샵 ID에서만 활성화하며, 다른 등록 샵은 변경하지 않는다. 서버에 저장된 메뉴·가격·주문은 수정하지 않는다. 공개 페이지 확인 중 보완하여 최종 패키지는 5.5.1이다.
