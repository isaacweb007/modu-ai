# v5.17 · 손님이 직접 바꾸는 통합 시연

프로덕션북 `#integrated-demo`의 QR·언어 선택 다음에 손님 입력 화면을 추가했습니다. 메뉴판 등록 → 사장님 확인 → QR → 언어 선택의 기존 시작 과정을 유지합니다.

- 매장 주문과 온라인 배달: 승인된 8개 메뉴에서 각각 0~20개를 선택합니다. 여러 메뉴를 함께 주문할 수 있고, 수량에 따라 합계를 즉시 계산합니다. 메뉴 가격과 통화(VND)는 사장님이 승인한 값으로 고정합니다.
- 예약: 날짜, 시간, 인원(1~20명)을 직접 입력합니다. 예약 시간은 샘플 샵의 베트남 시간(UTC+7)이며 오늘부터 365일 이내의 아직 지나지 않은 일정만 허용합니다.
- 배달: 주소와 국제 연락처를 입력합니다. 손님의 최종 확인, 한국어 통역, 홀·사장님 기록에 같은 내용을 보여줍니다. 주소는 번역 과정에서 바꾸지 않습니다.

수정한 메뉴와 수량, 예약 일정과 인원, 주소·연락처를 준비된 9개 언어 문장에 넣습니다. 사장님과 홀에는 한국어·원문, 손님에게는 선택한 언어의 답변과 마지막 알림을 보여줍니다. 주방에는 조리할 메뉴·수량·주문 상태·테이블/배달 구분만 보이고 금액·주소·연락처·예약 정보는 표시하지 않습니다. 예약은 홀 확인 → 사장님 알림으로 끝나며 주방 작업을 만들지 않습니다.

입력란에 포커스하면 자동 재생이 멈춥니다. ‘입력 확인 · 요청 보내기’ 또는 ‘다음 단계’는 같은 검증을 거칩니다. 빈 주문, 잘못된 수량·날짜·시간·인원·주소·연락처는 진행하지 못하고, 입력을 유지한 채 오류 요약과 해당 항목을 안내합니다. 오류 요약에서 입력란으로 이동할 수 있습니다. 책의 언어나 역할 화면을 바꿔도 작성 중인 입력은 유지합니다.

‘손님 요청 수정’을 누르면 기존 승인 메뉴를 유지하고 손님 입력 단계로 돌아갑니다. 이후 접수·완료 상태와 알림은 제거하고 다시 확인·접수하게 합니다. 수정 실행은 새 식별자로 분리하므로 이전 버튼이나 취소된 자동 재생이 새 요청을 진행할 수 없습니다. 시나리오 변경과 ‘처음부터’는 샘플 입력을 초기화합니다.

통합 시연은 프로덕션북의 페이지 메모리에서만 실행합니다. 실제 주문 저장, 계정 권한, AI, 결제, 메일, 외부 통역 호출을 추가하지 않았습니다. 입력값은 새로고침하면 사라지며 가상 정보로 체험하도록 안내합니다. QR이 여는 별도 손님 샘플 앱에는 프로덕션북에서 입력한 값을 전송하지 않습니다.

검증: 117개 테스트 통과. 9개 언어의 동적 문장과 폼, 여러 메뉴 합계, 예약 변경, 입력 검증, XSS 이스케이프, 주방 정보 제한, 수정 후 이전 동작 차단을 확인했습니다. 실제 브라우저에서는 390px 모바일 입력과 예약의 역할별 확인, 4개 화면 주문 상태 반영, 배달 오류 안내·입력 유지, 자동 재생 중 입력 시 정지를 검증했습니다. 기존 독립 시연을 포함한 전체 책의 모듈 번들 검사도 통과했습니다.
