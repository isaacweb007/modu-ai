# 원샵 5.10 — 네 역할 시연과 주문 대기 경험

2026-10-28 · 이전 공개 버전 5.9

프로덕션북의 매장 주문·예약·온라인 배달 시나리오를 손님, 홀, 주방, 사장님 네 화면으로 확장했다. 하나의 시나리오 상태에서 각 역할 화면을 렌더링하며 실제 주문 생성, AI 호출, 결제 처리는 하지 않는다. 한국어를 기본으로 유지하고 손님 시연 언어는 베트남어로 시작한다. 기존 아홉 언어를 모두 지원한다.

## 시연 흐름

1. 라미 인사와 손님 언어 선택.
2. 손님의 원문 주문 요청.
3. 사장님에게 원문과 한국어 뜻 표시.
4. 사장님의 준비된 답변을 손님 언어로 표시.
5. 손님의 메뉴·수량·가격·테이블 또는 배달 정보 확인.
6. 홀 직원 주문 접수.
7. 주방 직원 조리 시작.
8. 주방 준비 완료와 손님 언어 알림. 네 화면은 같은 주문 ID와 상태를 공유한다.

예약 시나리오는 홀 접수와 사장님 확인 알림을 사용하며 주방에 예약 처리 버튼을 만들지 않는다. 배달 주소·연락처는 손님·홀·사장님 화면에서 보이고 주방 화면에는 표시하지 않는다. 결제는 미결제 상태를 유지한다.

데스크톱은 네 화면을 나란히, 태블릿은 두 열, 모바일은 역할 버튼으로 전환한다. 모바일에서도 네 역할의 상태 요약을 항상 볼 수 있다. 자동 진행 화면 따라가기를 끄거나 역할 버튼을 누르면 선택한 역할을 유지한다. 재생·일시정지·다음·다시 시작과 모션 감소 설정을 지원한다. 탭이 가려지거나 시연 구역에서 벗어나면 자동 재생을 멈춘다.

## 손님앱 대기 경험

자신의 진행 중인 주문에만 대기 안내를 표시한다. 주문 카드 및 입력창 위에서 라미의 대기 대화를 열 수 있다. 메뉴 설명·샵 이야기·주문 확인은 기존 시나리오와 등록 정보에 기반하며 범용 AI를 연결하지 않는다. 로컬 샘플에서는 기존 가상 결제 후에도 대기 안내를 보여준다. 실시간 샵의 결제는 계속 미연결이다.

톤티비(TonTV)는 사용자가 지정한 https://t.me/TontvOfficialChannel 만 새 창으로 연다. 샵·방문·주문 정보를 URL에 넣지 않고 referrer도 전송하지 않는다. 채널을 자동 가입하거나 로그인하지 않는다. 원샵에서 무료로 제공하는 것은 연결 안내이며, Telegram 계정 필요 및 콘텐츠·이용 조건은 톤티비 기준임을 바로 옆에 명시했다. 백그라운드 푸시를 약속하지 않고 주문 알림 확인을 위해 앱으로 돌아오도록 안내한다.

2026-10-28 채널 URL의 공개 응답을 확인했다. 현재는 공식 공지 채널로 확인되므로 앱 내 재생기나 무제한 무료 콘텐츠를 제공한다고 표시하지 않는다. 공개 시청자 문구만 사용하며 수익·투자·토큰 관련 홍보를 복제하지 않는다.

## 사장님 접근 구분

손님앱의 사장님 버튼은 관리 페이지 이동 대신 전용 화면 안내를 보여준다. 통역 샘플 안의 사장님 바로가기도 제거했다.

명시적 store 파라미터가 있는 owner URL은 정확히 그 샵과 일치하는 저장된 사장님 자격이 필요하다. 없거나 형식이 틀리면 데모 로그인·새 샵 만들기·다른 현재 샵으로 넘어가지 않는다. store와 preview를 함께 넣어도 샘플 모드로 우회하지 않는다. 서버의 기존 owner 권한 검증은 그대로 유지하며 서버 거부 시에도 잠금 안내를 표시한다.

브라우저에 공용 비밀번호를 하드코딩하지 않았다. 프로덕션북에서 여는 공개 사장님 샘플은 다른 샵을 관리할 수 없다는 설명을 별도로 표시한다. 실제 사장님 로그인이나 비밀번호 인증을 구현한 것은 아니다. 사장님 권한이 저장된 같은 브라우저를 다른 사람에게 넘기는 경우의 기기 잠금은 별도 운영 범위다.

## 검증

- 67개 Node 테스트: 역할별 진행, 오래된 클릭 무시, 예약 분기, 언어 완결성, 자신의 주문만 대기 안내, 정확한 외부 링크, 명시적 샵 관리 접근 차단 및 기존 주문 회귀 검증.
- 브라우저에서 베트남어 주문을 사장님 통역 답변→손님 확정→홀 접수→주방 시작→준비 완료까지 수동 진행.
- 모바일 너비 390px에서 자동 재생 완료 및 손님 알림 확인.
- 샘플 주문·가상 결제 후 대기 안내, 사장님 진입 차단, 대기 중 시나리오 대화 확인.
- 톤티비 공개 시청자 문구 자동 감사: 1개 텍스트 파일, 실패·경고 0.
