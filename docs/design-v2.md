# 주모 손님 앱과 modu ai 2.0

사용자 첨부 두 화면의 둥근 유리 패널, 음식 중심의 레이아웃을 따르되 실제 주모의 기와·사발·레코드 심벌과 한식 메뉴로 구성한다. 기본은 따뜻한 밤, 선택 테마는 청록 유리. 음식이 가장 강한 시각 요소이고 장식은 줄인다.

- 먹빛 #191718, 목재 #35251d, 쌀빛 #f3eee3, 따뜻한 주황 #f3a44b, 옥스블러드 #8c2c28, 청록 #62d9d3.
- Pretendard 본문, 플랫폼의 각 문자권 기본 글꼴 폴백. 제목 44–76px, 모바일 36–44px, 본문 15–17px. 크메르·라오·힌디는 줄높이 확대.
- 모바일: 매장·언어 → 음식 히어로 → 메뉴 분류 → 사진 메뉴 → 고정 5탭과 장바구니. 데스크톱: 왼쪽 브랜드 내비게이션, 넓은 콘텐츠, 오른쪽 주문 요약.
- 채팅: 메뉴 화면과 별도 탭, 준비된 질문 + 텍스트 입력, 가게 범위 밖 거절·사용량 제한.
- 사장님: 선명한 주문·결제 상태, 이벤트 원문, 직접 불편 접수, 동의한 별명만. 연결되지 않은 POS는 미연결 표시.
- 프로젝트 북: 기존 18장 구성 유지, 9개 언어 전체 콘텐츠, 게스트/오너 체험 연결.

## 5종 디자인과 게임

Pretendard 가변 글꼴을 로컬로 제공하고, 한국어/라틴은 같은 글꼴 계열을 사용합니다. 크메르어·라오어·힌디어는 운영체제의 해당 문자 글꼴로 폴백하며 줄 간격을 확장합니다.

- 앰버 주막: 참고 이미지의 따뜻한 주황 강조, 큰 2줄 제목, 투명 패널.
- 청록 유리: 밝은 청록 배경광, 같은 음식 중심 구조와 투명 카드.
- 아이보리 테이블: 밝은 종이색 바탕, 좌측 사진의 가로 메뉴 목록.
- 딥 와인: 차분한 와인 바탕, 비대칭 큰 곡선 이미지 카드.
- 미드나이트: 푸른 밤색 바탕, 큰 둥근 카드와 차가운 강조색.

오너의 템플릿 미리보기는 실제 손님 앱을 iframe으로 띄웁니다. 미리보기 전용 메모리 상태를 사용해 실제 방문·주문·대화 기록을 늘리지 않습니다. 적용은 저장된 메뉴와 주문 데이터를 유지하고 템플릿 ID만 바꿉니다.

게임 로직은 `state.js`, 연출은 `guest.js`와 CSS에 분리했습니다. 결과는 연출 전에 저장해 새로고침으로 추첨을 반복하지 않습니다. 운영체제의 모션 줄이기 설정을 존중합니다. 서버가 없는 데모이므로 기기 조작에 대한 부정 이용 방지는 제품화 단계의 별도 요구입니다.
