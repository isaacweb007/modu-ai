# 4.0 검증 · 2026-10-27

- Node 검사 16개 통과: 9개 언어, 메뉴/주문, 시나리오 범위 제한, 게임, 온보딩, 예약, 포인트, 운영 메모, 새 서버 입력 검증.
- 서로 다른 소유자 2개·손님 2개의 독립 키로 실제 Supabase API 검증. 서버 금액 계산, 중복 주문 재시도, 메뉴 변경 거절, 주문 상태 전이, 예약 확인, 다른 손님 예약 취소 차단 통과.
- anon 직접 DB 조회 거부, 다른 매장 소유자의 조회/쓰기 거부, 손님의 관리 업로드 거부, 소유자 동시 수정 충돌 거부 확인.
- 공개 실시간 신호에는 개인·주문 내용이 없고, 권한이 있는 조회를 통해 새 주문이 도착함을 확인.
- 잘못된 이미지 시그니처 거부, 정상 이미지 업로드와 새 클라이언트의 서명 URL 다운로드 크기 일치 확인.
- 브라우저: 127.0.0.1의 사장님 앱에서 등록·사진 업로드·이름/가격 변경·게시. localhost의 별도 저장 영역 손님 앱에서 동일 매장·메뉴 확인 후 주문·예약. 사장님 대시보드에 새로고침 없이 표시되고 접수·예약 확인이 손님 화면에 반영됨.
- 손님 불편 문장이 소유자 대시보드와 대화 기록에 저장됨. 새로고침 후 가게·사진·주문·예약 유지 확인.
- 390×844 손님 화면: 가로 넘침 없음, 깨진 이미지 0. 기존 반응형 대화 UI 유지.
- Supabase 보안 advisor: 경고 없음. 성능 advisor의 복합 외래키 인덱스 안내 3개를 반영. Auth 연결 개수 기본 설정 INFO는 현재 미사용 Auth 서비스이며 유지.

AI 에이전트 답변·게임·포인트는 시나리오/미리보기, 실제 AI 모델·온라인 결제·POS·외부 알림은 미연결이다. 실제 매장 영업과 결제 검증은 이번 범위에 포함하지 않는다. 실험용 매장과 테스트 주문은 별도 가게 ID로 구분한다.
