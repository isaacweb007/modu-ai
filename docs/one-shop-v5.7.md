# 원샵 5.7 · 한 주문을 두 화면으로

프로덕션북의 `#live-demo`에서 손님앱과 사장님앱의 주문 흐름을 동시에 시연한다. 목차와 표지에 바로가기, 체험 장 첫 부분에 재생 화면을 배치했다.

## 시연

1. 손님이 베트남어로 김치전 1개를 요청한다.
2. 라미가 사장님에게 한국어 뜻과 원문, 7번 테이블을 함께 표시한다.
3. 사장님의 준비된 한국어 답변이 손님 언어로 표시된다.
4. 손님이 메뉴·수량·129,000 VND·7번 테이블을 확인하면 시연 주문 #001을 만든다.
5. 사장님이 접수하면 양쪽에 접수 완료를 표시한다.
6. 준비 시작 시 양쪽 주문을 준비 중으로 바꾼다.
7. 준비 완료 시 라미가 손님 언어로 안내한다.

전체 시연 시작 / 일시정지 / 이어서 재생 / 다음 단계 / 처음부터를 제공한다. 실제 역할 버튼을 눌러 단계별로 진행할 수도 있다. 자동 시연은 약 22초다. 다른 탭으로 이동하거나 시연 영역을 벗어나면 정지한다. 완료 시 재생은 종료한다.

데스크톱은 나란히, 모바일은 손님·사장님 화면 전환 버튼으로 표시한다. 진행 단계에 맞춰 활성 화면을 바꾼다. 시연을 시작하면 두 앱 영역으로 스크롤하고 재생 조작부는 위에 고정한다. 모션 줄이기 설정을 따른다.

## 언어와 데이터 경계

프로덕션북 기본 언어는 한국어, 시연 손님 언어는 베트남어다. 손님 언어는 기존 9개 언어를 지원하며 바꾸면 시연을 초기화한다. 사장님 화면은 요청대로 한국어를 유지한다. 기존 앱의 메뉴, 통역 문구, 주문 상태 문구와 테이블 정보 검증 함수를 재사용한다.

이 화면은 기존 두 앱 전체를 iframe으로 연결한 화면이 아니라, 프로덕션북 안에서 동일한 시나리오 상태를 함께 표시하는 두 앱의 시연 화면이다. 하단 링크로 기존 독립 앱도 열 수 있다.

`one-shop-book-showcase-v1`이라는 별도 sessionStorage 키에 언어·진행 단계·실행 ID·시작 시각만 보관한다. 새로고침은 정지된 상태로 복구한다. 다시 시작하면 새 시연 ID를 만든다. 기존 손님·사장님앱의 로컬 기록 및 클라우드 샵 주문은 변경하지 않는다. 실제 AI·결제·주문 API를 호출하지 않으며 결제 상태는 미결제다. 운영용 실시간 데모 샵의 동작은 기존과 같다.

## 검증

- `npm test`: 47개 통과. 9개 언어, 원문/한국어/답변 연결, 확정 전 주문 미생성, 동일 주문의 단계 변화, 테이블·수량·가격·미결제 보존, 중복 진행 방지, 복구값 검증, 취소된 타이머 무효화, 네트워크/샵 저장소 미참조.
- 로컬 브라우저: 베트남어 요청부터 사장님 답변·손님 확정·접수·준비·완료까지 역할 버튼으로 확인.
- 자동 재생 종료, 일시정지/재시작, 390px 모바일 탭 및 자동 활성 화면 전환, 일본어 손님/영어 책 전환, 가로 넘침 없음과 브라우저 오류 없음 확인.
- 기존 Sites의 소유자 전용 접근과 GitHub Pages 공개 배포 경로를 유지한다.
