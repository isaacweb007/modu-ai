# 원샵 · one shop ai 5.3

2026-10-27. 프로그램명은 원샵, 영문 브랜드는 one shop ai로 통일했다. 기존 GitHub 주소와 저장 키, API 식별자는 이미 발급한 링크와 샵 기록의 호환을 위해 유지한다.

## 주문과 예약

- 사장님앱의 새 주문·예약에 파란 매니저 알림을 표시한다. 처음 불러온 기존 내역은 새 알림으로 취급하지 않으며, 같은 스냅샷을 다시 받아도 중복 알림이 생기지 않는다.
- 주문은 최종 확인한 테이블 또는 배송 주소·연락처를 보여준다. 예약의 테이블은 접속한 QR의 출처이며, 확정 좌석으로 오인하지 않도록 표시한다. 온라인 예약은 테이블 미배정으로 구분한다.
- 접수 대기 → 접수 완료 → 준비 중 → 준비 완료 → 제공 완료를 사장님과 손님 화면에 동기화한다. 예약 확인·취소도 동기화한다. 결제 상태는 주문 진행과 별도로 유지한다.
- 수신한 갱신 신호가 다른 읽기·저장·주문 처리와 겹쳐도 버리지 않고 처리 후 다시 조회한다. 연결 문제가 있으면 기존 20초 보완 조회와 재연결 동작을 유지한다.
- 새 데이터가 도착해도 입력 중인 메시지·폼 값·선택 영역·스크롤을 보존한다. 한글 조합 중 전체 화면 갱신은 조합 종료까지 미룬다.
- 전체 개인정보를 실시간 공개 채널에 싣지 않는다. 기존 ID 알림 후 권한이 있는 샵/방문 스냅샷으로 상세를 조회한다.

## 데모를 연결하는 방법

사장님 샘플 로그인 → **실시간 데모 샵 열기** → **샵 링크와 QR**. 테이블용 또는 온라인용 QR·링크를 선택해 다른 휴대폰에서 연다. 연결 동작은 주모 샘플 정보와 메뉴만 새 샵에 준비한다. 기존 로컬 가상 주문은 클라우드에 실제 접수된 것처럼 복제하지 않는다. 같은 브라우저에서 다시 열면 기존 데모 샵을 재사용한다. 다른 기기의 사장님 로그인은 실제 인증을 도입할 때 제공한다.

## 프로덕션북

Higgsfield로 13개 신규 섹션 이미지를 만들었다. 기존 6개와 합쳐 표지 + 18개 장에 각각 다른 장면을 배치한다. 원본·프롬프트·생성 ID는 로컬 `design/one-shop-brand/book-v5.3/`, 웹용 1400px 이미지는 `dist/assets/one-shop/chapters/`에 저장했다. 원형 브랜드 타이포그래피, 확대·이동 이미지 모션, 곡선 드로잉을 추가했다. 화면 밖 모션은 재생하지 않고, 수동 모션 정지와 기기 모션 감소 설정을 존중한다.

## 검증

- 29개 단위·동작 검증: 신규 알림 중복 방지, 손님 세션 분리, 겹치는 실시간 갱신, 9개 언어 문구 포함.
- 클라우드 검증: 서버 가격, 중복 주문 방지, 테이블·온라인 정보 저장, 권한 분리, 공개 개인정보 차단, 예약, 미디어, 충돌 처리 통과.
- 별도 손님·사장님 브라우저 세션으로 테이블 8 주문, 다섯 진행 상태, 예약 확인, 입력 중 메시지 보존 확인.
- 가상 주소 `DEMO ONLY · District 1 · Room 503`과 예약 테스트용 전화번호로 온라인 주문 알림·대시보드 기록 확인.
- 모바일 390px 대시보드·온라인 QR와 한국어·힌디어 프로덕션북의 가로 넘침 없음 확인.
