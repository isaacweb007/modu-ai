# 모두의 AI 디자인 방향

2026-10-26. 참고한 FamilyWallet 북의 목차·긴 서사·작동하는 목업·사업 계산기 구조를 계승한다. 문장과 비주얼은 모두의 AI에 맞게 새로 작성한다.

- 색: 종이 #F6F7FA, 잉크 #17264A, 행동 파랑 #275CCB, 하늘 #DDEAFB, 식당 차양 코랄 #EE654B, 본문 회색 #526078.
- 글꼴: 한국어 중심 Pretendard Variable, 장 제목은 굵고 간결하게. 본문 17px / 1.85. 영어 장식 문구 최소화.
- 구성: 데스크톱 좌측 책갈피, 우측 본문. 첫 화면은 큰 한글 제목과 동네 가게 일러스트. 모바일에서는 목차 서랍. 길게 읽되 장마다 도표·대화·양식·계산기 등 정보에 맞는 구조로 전환.
- 원칙: 사장님의 시간과 손님의 식사에 집중한다. 실제 사용자의 어휘를 쓴다. 구현 예정·체험·제안·검증 목표를 구분한다. 실제 고객·매출·확정 제휴를 만들어내지 않는다.
- 검토: 일반 SaaS의 반복 카드·핑크 강조 추천은 본 프로젝트에 맞지 않아 채택하지 않았다. 테이블 모티프의 원형 심벌, 가게 차양색, 메뉴판형 체험으로 수정했다. UI/UX 스킬의 가독성·키보드·44px 터치·반응형·동작 줄이기 원칙은 반영한다.

간단 구조
```
책 이름 / 프로젝트 북                              체험 / 인쇄
목차        큰 비전 문장 + 동네 가게 그림
            왜 만드는가 → 누구를 위한가
            손님 체험 → 사장님 체험 → QR 인쇄
            운영 팀 → 사업 모델 → 공동 플랫폼
            설계 → 단계별 개발 → 함께 결정할 것
```
