# v5.14 · 메뉴판에서 샵 링크까지

프로덕션북의 `#setup-demo`는 샘플 사진 선택 → 첨부 → 라미의 메뉴 정리 → 사장님 검토 → 확인 → 샵 링크·QR 순으로 진행하는 독립 시나리오입니다. 기존 주문·예약·배달 네 화면 시연과 로그인·복구 시연은 유지합니다.

- 전체 시연 시작, 일시정지·계속, 다음 단계, 이전, 처음부터. 수동 검토 단계에서는 확인 버튼을 눌러야 다음으로 진행합니다. 자동 재생의 확인은 사장님이 실제 승인한 것이 아닌 준비된 시나리오임을 화면에 안내합니다.
- 메뉴판과 검토 목록은 기존 주모의 8개 메뉴·VND 가격을 공유합니다. 검토 전이나 확인 취소 후에는 링크·QR이 표시되지 않습니다.
- 한국어 기본, 기존 9개 언어의 UI·메뉴·QR 제공. 외국어 메뉴 아래 한국어 원명을 함께 표시하여 사진과 비교할 수 있습니다.
- 이미지 생성 도구로 제작한 메뉴판: `dist/assets/one-shop/onboarding/jumo-menu-photo.png`. 실제 사진 인식·업로드·AI 호출·계정 생성·결제는 하지 않습니다.
- QR은 로컬 qrcode-generator로 생성한 SVG입니다. M 오류 정정과 4모듈 여백을 사용하며 `node scripts/build-setup-qr.mjs`로 재생성합니다. 링크 복사, QR 저장, 손님앱 열기를 제공합니다.
- QR 목적지는 공개 GitHub Pages의 `jumo/?lang=ko&preview=1&sample=onboarding&table=7&v=5.14.0` 형태입니다. 이 경로는 라미 언어 선택으로 시작하며, 사진과 같은 메뉴를 메모리에만 구성합니다. 기존 샵이나 주문을 바꾸지 않고, 권한 토큰도 포함하지 않습니다. 사장님 로그인 접근 권한에는 영향을 주지 않습니다.
- 다른 시연 재생, 화면 이탈, 탭 숨김, 언어·레이아웃 변경 시 타이머를 정리합니다. 동작 감소 설정을 존중하며 자동 시작하지 않습니다.
- 데스크톱은 메뉴판과 대화 화면을 나란히, 모바일은 사진 미리보기와 대화를 세로로 표시합니다.

배포: 기존 GitHub Pages 공개 링크 및 기존 소유자 전용 Sites 미리보기. 메일·실제 AI·실제 결제·Supabase 변경 없음.

검증: `npm test` 99개 통과. 프로덕션북·손님앱 ESM 진입점 번들 검사 통과. 브라우저에서 수동 확인 후 QR 발급, 전체 자동 재생 종료, 언어 변경 시 진행 유지, 390px 모바일의 9개 언어 메뉴 표(각 8행, 가로 넘침 없음), 1440px 데스크톱, 베트남어 손님 첫 화면·메뉴 가격 일치를 확인했습니다. QR SVG 9종은 공개 샘플 URL과 재생성 결과를 대조했습니다.
