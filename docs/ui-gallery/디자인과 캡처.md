# 앱 UI 화면 모음

손님·오너·홀·주방의 실제 데모 화면을 이미지로 살펴보는 프로덕션북 장입니다. 기존 앱 체험과 통합 시연은 유지합니다.

## 디자인

- 색: 라미 블루 `#AEC8EB`, 잉크 `#172D46`, 액션 블루 `#315F99`, 구름 `#F5FAFF`, 흰색 `#FFFFFF`.
- 글꼴: 기존 프로덕션북의 Pretendard와 언어별 시스템 글꼴을 유지합니다.
- 구성: 장 제목 → 역할 선택 → 실제 화면과 설명 → 앱 체험 링크. 손님 4장, 오너 4장, 직원 3장입니다.
- 넓은 화면은 4열, 모바일은 2열로 비교하고, 이미지 확대 창에서 화면 전체를 읽습니다. 작은 휴대폰에서는 1열로 전환합니다.
- 장식보다 실제 앱 화면을 크게 보여줍니다. 자동 재생이나 자동 넘김은 없습니다. 확대 창은 닫기·이전·다음·키보드 탐색을 지원합니다.

## 캡처 출처

2026-11-02에 로컬 데모를 실제 실행하여 촬영했습니다. 별도 생성한 24시간 체험 샵에서 가상의 7번 테이블 주문을 만들고 홀 접수 → 주방 조리 → 준비 완료를 확인했습니다. 실제 고객이나 결제 내역은 사용하지 않았습니다. AI·결제·메일 서비스는 추가하지 않았습니다.

원본 PNG는 `원본/`, 공개용 WebP는 `dist/assets/ui-gallery/`에 저장했습니다. 화면 내용을 합성하거나 로그인 절차를 우회하지 않았습니다. 직원 화면은 홀과 주방의 기존 권한을 그대로 사용합니다. `staff-preparing.png`는 캡처 검수용이며 공개 목록에서 제외합니다.

이미지 안의 앱 언어는 한국어입니다. 제목·설명·탐색 버튼은 프로덕션북의 9개 언어를 지원하며, 이미지 자체가 번역된다고 표시하지 않습니다. 전체 직원 권한 화면은 세로로 길어 확대 창 안에서 스크롤해 볼 수 있습니다.

개인정보·접속 비밀값이 없는 화면만 사용합니다. 체험 샵의 관리 링크나 직원 초대 토큰은 소스·설명·공개 링크에 넣지 않습니다. 체험 시작은 기존 `#apps`의 연결 버튼에서 진행합니다.
