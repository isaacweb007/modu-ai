# v5.15 · 메뉴판부터 손님 알림까지 통합 시연

프로덕션북 `#integrated-demo`에서 약 1분의 준비된 시나리오를 하나의 재생기로 진행합니다. 표지와 사이드바에서 바로 열 수 있고 기존 메뉴 등록, 주문·예약·배달, 로그인·복구 시연도 유지합니다.

순서: 샘플 사진 선택 → 첨부 → 메뉴 정리 → 사장님 검토 → 승인 → QR 발급 → 라미 인사·손님 언어 선택 → 승인 메뉴 보기 → 베트남어 주문 요청 → 한국어·원문 통역 → 사장님 답변 → 손님 주문 확인 → 홀 접수 → 주방 준비 → 준비 완료·손님 알림.

15개 장면은 `integrated-demo-state.js`의 한 상태로 연결됩니다. 메뉴 8개와 VND 가격, 7번 테이블, 선택한 손님 언어와 주문 ID를 유지합니다. 홀은 접수, 주방은 준비·완료를 담당하며 잘못된 역할·단계·이전 재생의 동작은 거부합니다. 주문 상태는 접수 대기 → 접수 완료 → 준비 중 → 준비 완료로 바뀌며 결제는 계속 미결제입니다.

사장님 확인 전에는 QR과 주문 단계로 진행할 수 없습니다. 수동 시연은 확인 버튼을 거치며 자동 재생의 승인·QR 접속·주문 확인은 준비된 가상 동작이라고 안내합니다. QR 단계의 ‘이 QR로 손님 입장’은 같은 시연 안에서 언어 선택 화면으로 이어집니다. 실제 QR 이미지와 외부 샘플 앱 링크도 남겨 별도로 체험할 수 있습니다. 실제 카메라 접근이나 주문 생성은 없습니다.

15단계를 5개 구간으로 묶어 진행 상태를 표시합니다. 자동 재생·일시정지·계속·이전·다음·처음부터를 지원합니다. 뒤로 돌아가면 이후 주문·알림이 사라지고 승인 단계 이전에는 승인이 취소됩니다. 처음부터는 새로운 가상 주문 ID와 기본 베트남어로 시작합니다. 언어 선택 화면에서 9개 언어를 고를 수 있으며 책의 언어는 진행 상태를 유지한 채 변경합니다.

큰 화면에서는 손님·홀·주방·사장님 4개 화면, 모바일에서는 진행 역할을 자동 선택하고 역할 버튼으로 다른 화면을 확인합니다. 다른 시연 재생, 탭 숨김, 시연 영역 이탈, 언어·모바일 레이아웃 변경 시 타이머를 정리합니다. 동작 감소 설정에서는 애니메이션을 줄이고 자동 시작하지 않습니다.

기존 `showcaseViews`와 `shopSetupScreen` 화면 생성기를 추출해 공유하여 각 시연의 메뉴·통역·상태 표시를 일치시켰습니다. 실제 AI·결제·메일·업로드·인증·Supabase는 변경하거나 호출하지 않습니다. 가상 시연 상태는 페이지 메모리에만 있습니다.

검증: Node 테스트 106개 통과. 실제 브라우저에서 전체 15단계 수동 진행·자동 재생·정지·이어 재생을 확인했고, 네 화면의 주문 ID와 준비 완료 상태가 일치했습니다. 390px 모바일에서 현재 역할 화면을 따라가고 언어 선택 버튼을 누를 수 있는지 확인했습니다. 9개 책 언어 전환 시 단계 보존·가로 넘침·누락 문구를 점검했으며, 기존 예약·배달 완료와 주소·연락처 표시도 재검증했습니다.
