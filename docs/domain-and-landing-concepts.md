랜딩과 프로덕션북은 각각 별도 Sites 프로젝트와 배포로 운영한다. 원도메인에는 랜딩이 바로 표시된다. book 서브도메인의 CNAME과 TXT는 유지한다. 랜딩과 프로덕션북 모두 Sites 접근 모드를 public으로 운영한다. 2026-10-30 사용자의 공개 요청에 따라 프로덕션북을 custom에서 public으로 변경했다.

랜딩 원본은 작업폴더의 원샵 랜딩페이지이며 이 저장소의 landing-site는 소스 보관 사본이다. 이 사본에 프로덕션북의 배포 설정을 복사하거나 랜딩 설정으로 루트 배포 설정을 덮어쓰지 않는다.

한국어를 처음 방문의 기본으로 한다. 한국어·영어·베트남어·중국어·일본어·크메르어·인도네시아어·라오어·힌디어로 본문, 버튼, 이미지 설명, 체험 대화를 제공한다. 언어 선택은 URL과 브라우저에 유지하며 프로덕션북과 앱 데모 링크에도 전달한다. 크메르어·라오어·힌디어용 로컬 글꼴과 라이선스를 포함한다.

손님 언어 선택 → 메뉴 추천·주문 → 홀 접수·주방 준비 완료의 세 단계 체험을 제공한다. 주모 샘플 샵의 한국어 기록은 의도적으로 원문과 함께 보여준다. 모든 대화는 준비된 예시이며 실제 AI와 결제는 연결하지 않는다.
