# 라미 · 원샵 캐릭터 확장 5.4

라미는 동그라미에서 따온 원샵의 AI 에이전트 이름이다. 이미 승인한 파란 낙서 캐릭터의 동그란 몸, 비뚤한 검은 선, 작은 얼굴과 노란 신발을 보존한다. 플랫폼은 원샵 / one shop ai, 캐릭터는 라미 / Rami로 구분한다.

## 디자인 방향

밝은 흰 종이 위에 파란 동그라미가 살아 있는 캐릭터 북. 배경 white #FFFFFF, 보조 cloud #F5FAFF, 캐릭터 blue #AEC8EB, 텍스트 ink #172D46, 노란 포인트 #FFE395. Pretendard의 굵은 한글과 부드러운 소문자 rami를 크게 사용한다. 사이드바 카테고리는 작은 설명문이 아닌 읽기 좋은 굵은 제목으로 바꾼다.

캐릭터 소개는 큰 타이포그래피와 넓은 그림으로 시작한다. 표정은 선택 가능한 스티커 시트, 직업군은 캐릭터와 업무 소개, 굿즈는 실물 목업, BI는 실제 파일을 내려받는 자료실로 구성한다. 동일한 카드 격자로 모든 섹션을 채우지 않는다. 표정 24종은 각각 다른 이미지이며 번호만 바꾼 복제본을 사용하지 않는다.

## 구현 범위와 점검

- 9개 언어에 라미 이야기, 24종 표정명, 6개 역할, 굿즈·상품권 설명, BI 사용 기준 제공.
- 원본 래스터를 넣은 정확한 문자 SVG 로고, 앱 아이콘 3개 크기, 상품권 콘셉트 SVG, 다운로드 ZIP.
- 상품권은 발행·사용 가능한 상품권이 아닌 디자인 시안으로 명시한다.
- 모션은 짧은 반응과 작은 흔들림에 제한하고, 기존 일시정지 및 기기 동작 줄이기 설정을 따른다.
- 모바일 390px에서 표정 선택·파일 다운로드·목차·언어 전환 확인. 기존 주문·예약 데이터 흐름은 유지한다.
- 예상 위험: 24개 이미지의 과도한 세로 길이 → 6열/모바일 4열 스티커 시트. 긴 번역 → 줄바꿈과 유연한 너비. 원본 변형 → 생성 시 원본 참조 후 육안 검수.
