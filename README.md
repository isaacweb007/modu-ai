# 모두의 AI · modu ai

아이작스튜디오 × 원컴퍼니 재단. 9개 언어의 프로덕션북과 가게 에이전트 앱 4.0.

- [프로덕션북](https://isaacweb007.github.io/modu-ai/)
- [사장님 앱](https://isaacweb007.github.io/modu-ai/jumo/owner.html?lang=ko&v=4)
- [주모 손님 앱](https://isaacweb007.github.io/modu-ai/jumo/?lang=ko&v=4)

## 작동하는 흐름

사장님이 매니저와 대화하며 상호·주소·공개 연락처·SNS를 입력하고 메뉴 사진과 매장 사진·영상을 업로드합니다. 메뉴 이름·설명·가격·판매 여부를 확인하면 가게 고유 링크와 테이블 QR이 생성됩니다. 메뉴 추가·삭제도 가능합니다. 사진에서 메뉴를 자동으로 읽는 기능은 아직 연결하지 않았습니다.

다른 휴대폰이 QR로 접속하면 서버에 저장된 같은 가게와 메뉴를 읽습니다. 주문과 예약은 Supabase에 저장되고 사장님 대시보드에 실시간으로 반영됩니다. 사장님이 주문 접수·준비·완료, 예약 확인·취소를 처리하면 손님 화면도 갱신됩니다. 대화와 직원 요청·불편 사항도 해당 가게의 기록에 남습니다.

AI 에이전트 답변은 준비된 시나리오입니다. 실제 AI 모델, 온라인 결제, POS 전송, SMS·이메일 알림, 구독 청구는 연결하지 않았습니다. 실제 연결 모드에서는 결제 완료나 포인트를 임의로 만들 수 없습니다. 가위바위보·룰렛·결제·포인트의 기존 시뮬레이션은 `?preview=1` 체험에서 사용할 수 있습니다.

## 가게 관리 권한

첫 버전은 이메일·비밀번호 계정 대신 기기 관리 키를 사용합니다. 생성 후 **복구 코드 복사**로 코드를 따로 보관하세요. 다른 기기의 사장님 화면에서 **가게 관리 권한 → 내 가게 다시 연결**로 복원할 수 있습니다. 복구 코드를 가진 사람은 가게를 관리할 수 있으므로 공개하면 안 됩니다. 손님용 QR에는 가게 ID와 테이블 번호만 들어갑니다.

브라우저 데이터를 지운 뒤 복구 코드도 없으면 앱에서 관리 권한을 되찾을 수 없습니다. 이메일 인증, 직원별 권한, 관리 키 교체·회수는 다음 계정 단계의 작업입니다.

## 개발과 검증

```sh
npm ci
npm run build:vendor
npm test
npm run dev
```

`http://127.0.0.1:4318/jumo/owner.html?lang=ko`에서 등록합니다. 실제 공유 QR은 공개 GitHub Pages 주소를 사용합니다. 로컬 수정은 배포 후 공유 링크에 반영됩니다.

- `dist/`: 배포되는 앱·프로덕션북·이미지·아이콘·폰트
- `supabase/migrations/`: DB 스키마, 권한, 트랜잭션, 실시간 알림
- `supabase/functions/modu-api/`: 기기 관리 키 검증, 공개 매장 조회, 주문·예약·미디어 API
- `scripts/verify-cloud*.mjs`: 별도 소유자·손님 권한을 사용하는 실제 서버 통합 검증
- `docs/backend-v4.md`: API·보안·배포 구조
- `docs/verification-v4.md`: 확인한 범위와 제한

`npm run test:cloud`는 전용 개발 검증 매장과 주문·예약을 생성합니다. 관리 키는 git에서 제외된 `artifacts/`에만 0600 권한으로 보관됩니다. 기존 운영 데이터를 삭제하지 않습니다.

## 배포

GitHub `main` 푸시 → Actions의 의존성 설치·번들·검사 → GitHub Pages. 기존 Sites 주소는 소유자 전용으로 유지합니다. 사이트 소스와 배포 아카이브는 Sites source helper로 동일 커밋에서 저장합니다. 두 프런트엔드는 동일한 `modu-ai` Supabase 백엔드를 사용하며, 손님 QR은 공개 GitHub 주소로 생성합니다.

공개 설정은 `dist/shared/cloud-config.js`에 있습니다. 공개 가능한 프로젝트 URL과 publishable key만 포함합니다. 서버 관리 키는 Supabase Edge 런타임의 `SUPABASE_SERVICE_ROLE_KEY`를 사용하며 저장소·브라우저에 포함하지 않습니다.

언어: 한국어·영어·베트남어·중국어·일본어·크메르어·인도네시아어·라오스어·힌디어. 직접 작성한 메뉴 설명은 자동 번역하지 않으며, 변경하지 않은 주모 샘플은 9개 언어로 제공됩니다. 가격은 현재 VND 기준입니다. 음식 이미지는 AI로 만든 메뉴 시안입니다.
