# 모두의 AI 프로젝트 북

아이작스튜디오 × 원컴퍼니 재단 공동 플랫폼 구상을 정리한 웹 프로젝트 북 1.0.

## 실행

`npm run dev` → http://127.0.0.1:4318

빌드 과정이 없는 HTML·CSS·JavaScript 사이트입니다. `dist/`가 배포 결과물이며 이 안의 파일을 직접 수정합니다. `npm run check`로 JavaScript 구문을 검사합니다.

## 구현된 체험

- 18개 장과 표지, 목차 검색·현재 위치 표시·읽기 진행률, 반응형 목차.
- 한국어·영어·베트남어 손님 화면, 예시 메뉴 추천·재료 응답, 장바구니·수량·체험 주문.
- 가게 정보 입력, 사진 로컬 미리보기, 예시 메뉴 확인, 체험 링크 만들기.
- 실제 인코딩된 테이블 QR SVG 다운로드, 별도 A6 인쇄 화면.
- AI 담당 업무 탭, 요금 가설과 월 매출·공헌이익 계산기.
- 브라우저에 저장하는 논의 메모와 체크리스트, Markdown 내려받기.
- 브라우저 인쇄/PDF 저장용 스타일.

## 범위

실제 GPT 호출, 이미지 OCR, 매장 회원가입, 데이터베이스, 외부 주문 전송, 결제, SNS 연결, 구독은 연결하지 않았습니다. 체험에서는 이 사실을 화면에 표시합니다. 사진과 가게 입력은 서버로 전송하지 않습니다. 메모만 해당 브라우저 localStorage에 저장합니다.

Sites는 처음에 소유자 전용으로 게시됩니다. QR은 해당 사이트의 손님 체험 앵커를 가리키므로 비공개 상태에서는 외부 손님이 사용할 수 없습니다. 실제 매장용 QR은 향후 공개 매장 경로 및 서버의 테이블 검증을 연결해야 합니다.

## 파일

- `dist/index.html`: 프로젝트 본문과 체험 구조.
- `dist/styles.css`: 레이아웃·모바일·인쇄 스타일.
- `dist/app.js`: 체험, QR, 계산기, 메모.
- `docs/development.md`: 실제 제품 개발의 첫 범위와 완료 기준.
- `docs/design.md`: 디자인 결정.
- `docs/assets.md`: 표지 생성 프롬프트·자산 출처.

제안 요금, 파일럿 규모, 역할 분담은 확정된 사업 조건이 아닙니다. 실제 사용 실적과 허구의 후기는 기재하지 않았습니다.
