# 모두의 AI · modu ai

아이작스튜디오 × 원컴퍼니 재단의 가게 에이전트 플랫폼 프로덕션북과 주모(Jumo) 대화형 데모 3.0.

## 인터넷에서 보기

- 프로덕션북: https://isaacweb007.github.io/modu-ai/
- 손님 대화: https://isaacweb007.github.io/modu-ai/jumo/?lang=ko
- 사장님 매니저: https://isaacweb007.github.io/modu-ai/jumo/owner.html?lang=ko

## 로컬 실행

Node.js 22 이상과 Python 3에서 실행합니다. 별도 npm 패키지 설치나 API 키가 필요하지 않습니다.

```sh
npm test
npm run dev
```

http://127.0.0.1:4318 에서 책을, `/jumo/`에서 손님 앱을, `/jumo/owner.html`에서 사장님 앱을 봅니다. `dist/`가 배포 파일입니다.

## 3.0의 흐름

Grok처럼 간결한 단색 대화 UI로 전환했습니다. 기존 5개 디자인 선택과 음식 앱 중심의 탐색 화면은 제거했습니다.

- 사장님: 매니저 대화 → 데모 시작 → 상호 → 메뉴 사진 → 매장 사진·영상 → 국가·주소·연락처·SNS → 예시 메뉴와 가격 검토 → 가게 링크와 QR.
- 손님: 대화로 문의 → 메뉴 카드에서 선택 → 주문 확인 → 데모 결제 → 포인트 적립·서비스 쿠폰. 날짜·시간·인원을 넣어 예약 요청을 남길 수 있습니다.
- 매니저: 주문·예약 확인, 결제 완료 금액 보고, 자재 수량 입력, 직원 업무 기록, 결제 내역 CSV 내보내기. 단일 대시보드에서 주문·예약·요청·대화·혜택을 확인합니다.
- 매장 관련 시나리오 응답과 가게 외 질문 제한. 방문당 15회·일 100회의 질문 예산 예시. 정형 주문·예약 카드는 모델 호출 없이 처리하는 구조입니다.
- 무료 가위바위보·4칸 룰렛. 게임별 방문당 1회, 게임 보너스는 방문당 최대 1개. 데모 결제 1,000₫당 1P, 100P로 작은 김부각 쿠폰. 포인트 쿠폰은 게임 보너스와 별도입니다.
- 한국어·영어·베트남어·중국어·일본어·크메르어·인도네시아어·라오어·힌디어. 18개 장의 책과 앱 문구에 적용했습니다.

## 데모의 경계

GPT API, OCR, 실제 주문·예약·결제·구독 청구, 회원 인증, POS 서버는 연결하지 않았습니다. 채팅은 키워드와 준비된 시나리오로 답합니다. 사진을 분석했다고 가장하지 않으며 주모 예시 메뉴를 검토합니다. 가게 정보는 직접 입력하고, 등록되지 않은 사실은 직원 확인을 안내합니다. 메뉴 가격은 VND 예시이며, 음식 이미지는 AI 콘셉트입니다. 세무 자료는 데모 결제 내역이며 세율 계산·신고·상담 기능이 아닙니다.

정보와 진행 상태는 해당 사이트의 해당 브라우저 localStorage에, 첨부 파일은 IndexedDB에 저장합니다. 다른 기기·브라우저·호스팅 주소에는 동기화되지 않습니다. 이미지 최대 5MB, 매장 영상 최대 25MB, 한 번에 최대 3개를 선택합니다. 서버로 파일을 전송하지 않습니다. 브라우저 사이트 데이터를 삭제하면 기록과 파일이 사라집니다.

QR로 접속해도 실제 개인정보나 회원 정보가 자동 수집되지 않습니다. 예약에는 테스트 닉네임만 사용하세요. 사장님 화면은 공개 체험용으로 실제 운영 권한이나 인증을 제공하지 않습니다. `?preview=1`은 세션·주문·채팅·게임·첨부를 메모리에만 저장합니다. 새 대화는 화면을 새로 시작하며 방문 기록과 주문·포인트는 유지합니다.

GitHub Pages는 공개 체험 링크입니다. 기존 Sites 주소는 소유자 전용 접근 설정을 유지합니다. 실제 매장용으로 전환할 때는 가게별 DB·인증·서버 예산 제한·결제 검증·POS 어댑터가 필요합니다. 브라우저 한도와 게임 결과 검증은 데모이며 실제 보안 경계가 아닙니다.

## 소스와 에셋

- `dist/book.js`, `book-content.js`, `book.css`: 9개 언어 프로덕션북과 내장 앱 미리보기.
- `dist/jumo/conversation.js`, `conversation.css`: 손님·사장님 대화 UI와 대시보드.
- `dist/shared/conversation-state.js`, `state.js`, `chat.js`: 개설·예약·결제·포인트·주문·게임·시나리오 로직.
- `dist/shared/media.js`: 브라우저 첨부 파일 보관.
- `dist/shared/conversation-copy.js`, `copy.js`, `menu.js`: 다국어 문구와 메뉴.
- `dist/jumo/print.html`, `print.css`, `print.js`: QR SVG 및 A6 인쇄.
- `dist/jumo/assets/`: 주모 음식·게임 이미지. `source-assets/higgsfield/`: 원본 이미지와 생성 기록.
- `dist/api/pos-contract.json`: 실제 서버가 아닌 POS API 설계 초안.
- `tests/demo.test.mjs`: 주문·가격·품절·한도·게임·개설·예약·결제·포인트·기록 검증.
- `docs/design-v3.md`, `docs/verification.md`: 디자인 기준과 검증 기록.

## 배포

`main` 브랜치를 GitHub에 푸시하면 `.github/workflows/pages.yml`이 테스트 후 `dist/`를 GitHub Pages로 배포합니다. Sites 배포는 `.openai/hosting.json`의 기존 프로젝트와 접근 설정을 유지합니다. 비밀값이나 방문 기록은 저장소에 추가하지 않습니다.

번역은 데모용 초안입니다. 출시 전 현지어 검수와 메뉴 재료·알레르기·가격 확인이 필요합니다.
